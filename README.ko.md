# Arcaea 아이쨩 추천곡 조회

[English](README.md) · **한국어**

Arcaea 7.3.0의 파트너 ID 75, 아이쨩의 `skill_aichan`이 고르는 일일 추천곡 3개를 재현하는 오프라인 도구입니다. 같은 유효 날짜와 곡 카탈로그를 사용하면 같은 순서로 같은 곡이 나옵니다.

## 브라우저에서 조회

[아이쨩 추천곡 뷰어 열기](https://chogang.github.io/aichan/)

오른쪽 위 버전 번호 아래에서 한국어, 영어, 일본어, 중국어 간체 중 하나를 선택할 수 있습니다. 필터 아래의 **EN**·**JP** 체크박스로 결과와 내보내기에 표시할 곡명을 선택합니다.

기준 시각은 화면 언어에 따라 한국 표준시, 미국 동부 시간, 일본 표준시, 중국 표준시로 표시합니다. 언어를 바꿔도 선택한 추천일과 추천곡은 그대로입니다.

1. 시작일을 입력합니다. 종료일과 일수를 모두 비우면 시작일 하루만 조회합니다. 기간을 지정하려면 두 항목 중 하나를 입력합니다. 한쪽에 값을 입력하면 다른 쪽은 비활성화됩니다. **초기화**를 누르면 시작일을 유지한 채 종료일과 일수를 비웁니다. 시작일을 1일째로 셉니다. **오늘**은 하루를, **7일·30일·365일**은 오늘부터 해당 일수만큼 조회합니다.
2. **추천곡 조회**를 누르면 날짜마다 추천곡 3곡이 표시됩니다. 양끝 날짜를 포함하며, 긴 기간은 최대 365일씩 페이지로 나뉩니다. 페이지 이동 버튼으로 나머지 기간을 조회할 수 있습니다.
3. **텍스트 내보내기**에서 **전체 복사** 또는 **TXT 저장**을 눌러 현재 페이지를 내보냅니다. **곡 팩 포함**과 **곡 난이도 포함**은 기본으로 켜져 있으며, 브라우저 저장소를 사용할 수 있으면 두 옵션의 선택 상태를 기억합니다.

**곡 검색**에 곡명, 아티스트 또는 곡 ID를 입력하면 현재 페이지의 결과를 좁힐 수 있습니다. **난이도**와 레벨 범위는 같은 채보에 적용되며 최저·최고 레벨을 모두 포함합니다. 예를 들어 `9+`는 `9`와 `10` 사이에 해당합니다.

날짜별 **복사** 버튼은 그날의 필터 결과와 재킷을 복사합니다. **공유** 버튼과 복사 내용의 마지막 줄은 해당 날짜의 전체 추천곡 링크를 사용합니다. 미리보기는 세로형 곡 카드 세 장을 나란히 배치합니다. 재킷 위에 팩 이름과 무료·유료 배지를, 아래에 곡명과 FTR·ETR·BYD·INS 레벨을 표시합니다. 미리보기와 링크를 열었을 때의 뷰어는 공유 시 선택한 언어를 따릅니다. 날짜가 없는 링크는 오늘을 조회합니다. 붙여넣는 앱에서 HTML 붙여넣기와 외부 이미지 로딩을 지원하면 재킷이 표시됩니다. [날짜 지정 공유 링크](https://arcaea-aichan-api.pages.dev/share?date=2026-11-18&lang=ko) · [오늘 공유 링크](https://arcaea-aichan-api.pages.dev/share?lang=ko)

뷰어와 링크 미리보기는 Arcaea 곡 데이터에 구매 항목이 지정된 곡을 **유료**, 구매 항목이 빈 곡을 **무료**로 표시합니다. 실제 플레이 가능 여부는 계정의 구매 내역과 월드 모드 해금 상태에 따라 달라집니다.

추천 날짜는 한국 시간 오전 5시에 바뀝니다. 오전 5시 전에 **오늘**을 선택하면 전날 추천곡이 표시됩니다. 오프라인에서는 [뷰어 HTML](docs/index.html)을 내려받아 브라우저에서 열면 됩니다.

뷰어에서 지정할 수 있는 날짜는 2025-11-08부터 2099-12-31까지입니다.

## 명령줄에서 조회

Node.js가 필요합니다. 저장소에서 다음 명령을 실행하면 추천곡 ID, 제목, 아티스트, 팩 ID와 적용 구간을 JSON으로 출력합니다.

```sh
node aichan-recommend.js
node aichan-recommend.js --date '2026-11-18T05:00:00+09:00'
node aichan-recommend.js --seed 20775
```

인수를 생략하면 실행 시각을 사용합니다. `--date`에는 시간대가 포함된 ISO 8601 시각을 지정합니다. `songlist.json`에는 곡 인덱스·ID·표시용 메타데이터가 있습니다. 같은 구조의 별도 카탈로그는 `--catalog`로 지정할 수 있습니다.

## JSON API로 조회

[추천곡 API 주소](https://arcaea-aichan-api.pages.dev/api/recommendations)에 `GET` 요청을 보냅니다. `date`와 `seed` 중 하나를 지정할 수 있습니다.

| 요청 경로 | 결과 |
|---|---|
| `/api/recommendations` | 오늘의 추천곡. 한국 시간 오전 5시에 추천일이 바뀝니다. |
| `/api/recommendations?date=2026-11-18` | 지정한 `YYYY-MM-DD` 날짜의 오전 5시(KST)부터 적용되는 추천곡. |
| `/api/recommendations?seed=20775` | `20400` 이상 `10000000` 이하의 정수 시드에 해당하는 추천곡. |

응답 JSON에는 `day_index`, `effective_period_utc`, `songs`가 포함됩니다. 각 곡의 `difficulties` 배열에는 뷰어와 동일한 채보 난이도와 표시 레벨이 들어갑니다. 예를 들어 `[{"difficulty":"FTR","level":"9+"}]`처럼 `+`를 보존하기 위해 레벨은 문자열로 반환합니다. 채보 정보가 없으면 빈 배열을 반환합니다. 잘못된 인자, 중복 인자, `date`와 `seed`를 동시에 지정한 요청에는 HTTP `400`과 JSON `error`가 반환됩니다.

저장소 루트에서 `npm ci`와 `npx wrangler pages dev`를 실행하면 로컬 서버의 `/api/recommendations`와 `/share-card?date=2026-11-18`에서 API와 미리보기 PNG를 확인할 수 있습니다. Node.js 22 이상에서 `node verify-api.mjs`로 CLI와 API를 대조하고, `node verify-share.mjs`로 공유 미리보기 메타데이터와 뷰어 링크를 확인합니다.

## 곡 데이터 갱신

Arcaea의 전체 `songlist.json`을 갱신 스크립트에 전달합니다. 팩 표시명을 반영하려면 `packlist.json`도 전달합니다. 생략하면 기존 팩 이름을 사용하고 새 팩은 ID로 표시합니다.

```sh
node scripts/update-catalog.cjs --dry-run FULL_SONGLIST.json PACKLIST.json
node scripts/update-catalog.cjs FULL_SONGLIST.json PACKLIST.json
node verify-api.mjs
node verify.js
```

스크립트는 입력을 검증하고 CLI 곡 목록, API 난이도 데이터, 뷰어의 암호화된 곡 데이터 블록을 갱신합니다. 생성된 변경 사항을 확인하고 해당 파일을 커밋합니다. 뷰어는 단일 HTML로 오프라인에서 계속 열 수 있습니다. 공개 API에도 새 데이터를 반영하려면 GitHub Pages 뷰어와 별도로 API를 배포합니다.

재킷 썸네일을 갱신하려면 `song-jackets.json`에 곡 ID와 32자리 소문자 16진수 해시를 적고 같은 명령을 다시 실행합니다. 뷰어는 목록을 표시할 때 `https://webassets.lowiro.com/<hash>.jpg?v=323` 주소를 만듭니다. 해시가 없거나 이미지를 불러올 수 없는 곡은 썸네일 없이 표시합니다.

선곡 알고리즘은 Arcaea 7.3.0을 기준으로 합니다. 곡 데이터를 갱신하면 과거 날짜의 추천곡도 달라질 수 있으며, 게임이 업데이트되면 알고리즘이 바뀌었는지 확인해야 합니다.

곡 목록이나 공유 카드 번역에 새 문자가 추가되면 `python -m pip install fonttools==4.60.1`과 `python scripts/build-share-font.py 'NotoSansJP[wght].ttf' 'NotoSansKR[wght].ttf' 'NotoSansSC[wght].ttf'`를 실행해 공유 카드 글꼴을 갱신합니다. `share-assets/`에 생성된 글꼴을 텍스트 변경과 함께 커밋합니다. 원본 글꼴의 라이선스는 `share-assets/OFL.txt`에 있습니다. [Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp) · [Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr) · [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)

## 추천곡을 고르는 순서

1. **날짜를 시드로 변환합니다.** 앱은 런타임 시각 보정과 로그인·시각 유효성 확인을 거칩니다. 유효 시각을 Unix 밀리초로 나타내면 시드는 `floor((유효 시각 + 14_400_000) / 86_400_000)`입니다. 4시간을 더하므로 유효 날짜 경계는 UTC 20:00, 한국 시간 오전 5시입니다. 앱은 같은 날짜의 추천 목록을 재사용합니다. 조회 도구는 지정한 시각을 유효 시각으로 간주합니다.
2. **인덱스 후보를 섞습니다.** `0`부터 `4999`까지 배열을 만들고, 세 난수 상태를 모두 날짜 시드로 초기화합니다. 아래 갱신식을 사용해 난수 하나를 만들 때마다 배열의 뒤쪽부터 한 자리씩 바꿉니다.

   ```text
   x = (171 × x) mod 30269
   y = (172 × y) mod 30307
   z = (170 × z) mod 30323
   r = ((x / 30269 + y / 30307) + z / 30323) mod 1

   i = 4999부터 1까지
       r = 다음 난수
       j = trunc(float32(r × i))
       swap(array[i], array[j])
   ```

   나눗셈과 덧셈, 교환 위치를 구하는 곱셈은 각각 단정도(`float32`)로 계산합니다. 이 구현의 곱수는 `i`이므로 각 교환 상대는 `0…i−1`에서 정해집니다. `Math.fround`로 원본의 단정도 연산을 반영합니다.
3. **배열을 앞에서부터 읽으며 3곡을 채웁니다.** 각 숫자는 곡 데이터의 행 번호가 아니라 `idx`입니다. 등록곡이 없는 값과 곡 ID `lasteternity`를 건너뜁니다. `set == "base"` 또는 `id == "innocence"`에 해당하는 첫 곡 1개와, 그 외 분류에서 처음 만나는 2개를 선택합니다. 결과에는 발견 순서와 곡 ID가 유지되며, 난이도 선택은 포함되지 않습니다.

시드 `20775`(한국 시간 2026-11-18 05:00부터 다음 날 05:00 직전까지)에서는 셔플 배열의 2·7·12번째 값이 추천에 들어갑니다.

| 위치 | `idx` | 곡 | 분류 |
|---:|---:|---|---|
| 2 | 521 | +1(UNKNOWN)-NUMBER | 기타 첫 곡 |
| 7 | 263 | DDD | 기본 분류 |
| 12 | 468 | Syriana | 기타 두 번째 곡 |

## 구현 검증

Arcaea 7.3.0의 ARM64 코드에서 `skill_aichan`의 생성자가 `CharacterAbilityPreferredSongDaily`에 연결되는 경로를 확인했습니다. 해당 타입의 활성 파트너를 판별한 뒤 호출되는 함수를 따라 날짜 계산, 셔플 연산과 곡 분류 조건을 복원했습니다.

검증을 실행하려면 Node.js와 Java 소스 실행을 지원하는 JDK 11 이상이 필요합니다.

```sh
node verify.js
```

이 명령은 Java의 `float`로 구현한 셔플과 JavaScript의 `Math.fround` 구현을 **43개 시드 × 5,000개 인덱스**에 대해 순서까지 비교합니다. 이어서 실제 카탈로그의 `idx` 중복 여부와, 한국 시간 오전 5시 경계 직전·직후의 시드 및 곡 ID를 CLI 출력과 대조합니다.

| 한국 시간 | 시드 | 예상 곡 ID |
|---|---:|---|
| 2026-11-18 04:59:59.999 | 20774 | `mantis`, `callmyname`, `diode` |
| 2026-11-18 05:00:00.000 | 20775 | `unknownnum`, `ddd`, `syriana` |

브라우저에서도 위 곡 순서를 확인할 수 있습니다. `2026-11-18` 하루를 조회하면 `unknownnum`, `ddd`, `syriana`가 표시됩니다. `2026-11-17`부터 `2026-11-18`까지 기간을 설정하면 양끝 날짜를 포함해 6곡이 나옵니다. **곡 ID 포함**을 켜고 화면과 내보내기 텍스트를 대조하거나 **TXT 저장**으로 저장 결과를 확인합니다.

이 검증은 정적 분석에 따른 재현 구현을 대상으로 합니다. 실제 게임 화면과의 대조, 앱의 런타임 시각 보정값과 로그인 상태 재현, 곡 등록 필터 전체 확인은 검증 범위에 포함되지 않습니다. 게임 버전이나 카탈로그가 바뀌면 실제 목록도 달라질 수 있습니다.
